Deskripsi

Program ini menghitung rata-rata, mencari nilai terendah, dan menentukan status debit air berdasarkan nilai yang dimasukkan.

Menjalankan Program

Jalankan perintah berikut di terminal:

python debit.py

Menjalankan Pengujian Manual

Jalankan perintah:

python uji_manual.py

Program pengujian memeriksa fungsi hitung_rata_rata(), cari_terendah(), dan cek_status().
